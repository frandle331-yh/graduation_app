# KajiMate 🏠

> ふたりの家事を、データで見える化する。

**🔗 アプリURL：** https://kajimate.com
**🎬 ゲストログイン：** ログインページの「ゲストとして試す」からすぐに試せます

---

## 📌 サービス概要

同居するカップル・夫婦の「家事分担の偏り」を、データで可視化するWebアプリです。

「私ばっかり家事してる」「ちゃんとやってるのに伝わらない」——こういったすれ違いは、
主観と感情によるものがほとんどです。

KajiMateは **「誰が・いつ・何をやったか」という事実を記録・蓄積** することで、
感情論に陥らず、冷静に分担を見直せる仕組みを提供します。

## 💡 制作の背景・解決したい課題

共働きが主流となった現代、家事分担は多くのカップル・夫婦にとって悩みの種です。

既存の家事アプリを調査したところ、多くは **「やるべき家事を管理するタスク型」** でした。
「やった家事の実績を継続的に蓄積・分析する」ことに特化したアプリは少なく、ここに優位性があると判断しました。

また、これから自身が同居生活を始めるにあたり、
「データで話し合える仕組み」を自分で作りたいという実体験からの動機もあります。

## ✨ 主な機能

### 🎯 ワンタップ記録（テンプレート + クイック記録）
- よく使う家事をテンプレート登録し、**タップ1回**で今日の家事を記録
- ダッシュボードに**直近5件の記録**を表示し、ワンタップで再記録
- カテゴリ選択後に**過去ログ+デフォルト候補をチップ表示**してタイトル入力を省略
- タイトル未入力時は**カテゴリ名を自動セット**（入力の摩擦ゼロ）

### 📊 ダッシュボード（多機能分析画面）
- **週次サマリーカード**：記録数・合計時間・前週比・1日あたり平均・よくやった家事
- **日別棒グラフ / カテゴリ別ドーナツグラフ**（Chart.js）
- **貢献バランスバー**：世帯メンバーの分担割合を視覚的に比較
- **ストリーク表示**：連続記録日数と今週の記録日をモチベーション表示
- **月間カレンダー**：記録日をドットで表示
- **期間切り替え**：今週・今月・全期間

### 🏅 ゲーミフィケーション
- **10種類の達成バッジ**（はじめの一歩、3日連続、7日連続、30日連続、500分突破など）
- **記録完了アニメーション**：登録成功時に絵文字パーティクルが弾ける演出
- **ストリーク表示**：連続記録で炎アイコンが変化

### 📋 家事ログ一覧・絞り込み・検索
- 期間・カテゴリ・並び順での絞り込み
- タイトルの**オートコンプリート検索**（Stimulus + APIエンドポイント）
- ミニ統計ヘッダー（件数・合計時間・最多カテゴリ）
- ページネーション対応

### 👫 世帯機能・招待コード参加
- 世帯作成で**ランダム8桁の招待コード**を発行
- **LINEシェア / Web Share API**で簡単にパートナーへ共有
- **ありがとうリアクション**：パートナーの家事ログに感謝を送信
- **家族タイムライン**：世帯メンバーの家事ログを時系列で一覧表示

### 👤 マイページ
- 累計記録数・累計時間・連続記録日・バッジ獲得数
- **活動ヒートマップ**（直近90日、GitHub風のグリッド表示）
- **カテゴリ別記録数バー**
- 設定メニュー（プロフィール編集・世帯・ログアウト）

### 🌙 ダークモード
- OS設定に連動した**自動検出** + ヘッダーからの**手動切替**
- CSSカスタムプロパティによるテーマ切り替え
- `localStorage` + インライン `<script>` でちらつき防止

### 📱 PWA対応・モバイル最適化
- **PWAマニフェスト**でスマホホーム画面にインストール可能
- **ボトムナビゲーション**：スマホではタブバーUIで直感操作
- **44px以上のタッチターゲット**確保（iOS/Androidアクセシビリティ準拠）
- **カテゴリアイコングリッド**：selectの代わりにアイコンで視覚的に選択
- **時間プリセットボタン**：5/10/15/30/60分をワンタップ入力

### 🔐 認証
- Deviseによるメールアドレス登録
- **Googleログイン**（OmniAuth）
- **ゲストログイン**（登録不要で即体験）

## 🔍 実装で工夫したポイント

### 1. 「記録の摩擦ゼロ」を追求したUX設計

家事記録アプリの最大の敵は **「面倒くさくて続かない」** こと。以下の工夫で入力コストを極限まで下げました：

- **タイトル自動補完**：カテゴリ選択だけで記録可能（`before_validation`でカテゴリ名を自動セット）
- **カテゴリ別サジェスト**：過去ログの使用頻度順 + デフォルト候補をAjaxで取得しチップ表示
- **時間プリセット**：5/10/15/30/60分をワンタップで入力
- **カテゴリアイコングリッド**：selectの代わりにアイコンで直感選択
- **日付初期値**：今日の日付を自動セット
- **テンプレート + クイック記録**：過去の記録をワンタップで複製

### 2. トランザクション処理による世帯作成の整合性担保

世帯作成時に `Household` レコードと `HouseholdMember` レコードを同時に作成する必要があります。
どちらか一方の保存に失敗した場合にデータが中途半端な状態にならないよう、`ActiveRecord::Base.transaction` を使って原子的に処理しています。

```ruby
Household.transaction do
  @household.save!
  HouseholdMember.create!(household: @household, user: current_user, role: :owner)
end
```

### 3. ソフトデリートによる退会実装

ユーザーが退会してもデータを物理削除せず、`withdrawn_at` にタイムスタンプを記録する設計にしました。
Deviseの `active_for_authentication?` をオーバーライドすることで、退会済みユーザーのログインを防ぎつつ、関連データの整合性を維持しています。

```ruby
def active_for_authentication?
  super && withdrawn_at.nil?
end
```

### 4. CSSカスタムプロパティによるダークモード

ダークモードは `@media (prefers-color-scheme: dark)` と `data-theme` 属性を組み合わせて実装。
ちらつき防止のため、`<head>` 内のインライン `<script>` で `localStorage` からテーマを即座に適用しています。

```javascript
// ちらつき防止: CSS読み込み前にテーマを適用
(function(){var t=localStorage.getItem("theme");if(t)document.documentElement.setAttribute("data-theme",t)})();
```

### 5. Turbo + OmniAuth の競合解消

Rails 8 の Hotwire（Turbo）環境では、`button_to` が生成するPOSTフォームをTurboがXHRとしてインターセプトするため、`omniauth-rails_csrf_protection` のCSRF検証が失敗します。
GoogleログインボタンのみTurboを無効化（`data: { turbo: false }`）することで解消しました。

### 6. Stimulusコントローラーによるインタラクション

SPAフレームワークを使わず、**10個のStimulusコントローラー**でリッチなインタラクションを実現。
`eagerLoadControllersFrom` による自動登録で、新規コントローラー追加時の設定コストをゼロにしています。

### 7. モバイルファーストのレスポンシブ設計

- ボトムナビゲーション（640px以下で表示、デスクトップメニューと切り替え）
- 44px以上のタッチターゲット確保
- `env(safe-area-inset-bottom)` でiPhoneのノッチ対応
- PWAマニフェストでネイティブアプリ風の体験

### 8. GitHub Actions による4重CI

すべてのPRに対して以下を自動実行：
- **RSpec**：132テストで機能の正常動作を担保
- **Rubocop**：コードスタイルの統一
- **Brakeman**：セキュリティ脆弱性の静的解析
- **bundler-audit**：依存gemの既知脆弱性チェック

## 📊 競合サービスとの比較

| アプリ | 主目的 | KajiMateとの違い |
|---|---|---|
| CAJICO | ポイント・感謝スタンプ | 実績データの継続分析には不向き |
| PikaPika | 掃除スケジュール管理 | 掃除限定・貢献度比較なし |
| ペアワーク | 家事時間の時給換算 | 記録コストが高く継続しづらい |
| **KajiMate** | **実績ログの蓄積・分析** | **記録の摩擦ゼロ × データ可視化 × ゲーミフィケーション** |

## 🚀 ローカル環境での起動手順

```bash
# リポジトリをクローン
git clone https://github.com/frandle331-yh/graduation_app.git
cd graduation_app

# gemのインストール
bundle install

# データベースのセットアップ
bin/rails db:create db:migrate

# サーバー起動
bin/rails server
```

`http://localhost:3000` にアクセスしてください。

**動作環境**
- Ruby 3.2
- Rails 8.1
- PostgreSQL 16
